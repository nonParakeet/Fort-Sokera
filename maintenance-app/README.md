# Maintenance Scheduler App

This directory contains the React/Vite frontend for the Fort Sokera Maintenance Scheduler. The dashboard is currently a static prototype; it has no backend or persistent storage.

For the project description and full setup instructions, see the [repository README](../README.md).

## Quick start

Requirements: Node.js 20.19+ or 22.12+ and npm.

```bash
npm ci
npm run dev
```

Run `npm run build`, `npm run preview`, or `npm run lint` here to build, preview, or lint the application.
